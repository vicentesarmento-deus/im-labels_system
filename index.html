Labels in a post (exploring interactions)

Three prototypes of the labels section on an evaluation post, made to answer one question: is it better to resolve label changes in place on the page, or inside a modal? Each is a working page, not a mockup.

v3 Save flow — in place vs modal The two candidates side by side. A resolves every action on the page; B resolves everything inside an “Edit labels” modal. Same rules underneath, so a preference comes from the model, not the feature set.
